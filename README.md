# Skills

My favorite coding style, presented by skills.

## Bundles

- [`coop/`](coop/) - AI-human cooperation commands, each scoped to one small problem: `!coop do`, `!coop try`, `!coop check`, `!coop diag`.
- [`mem/`](mem/) - project memory carried across sessions: `!mem init`, `!mem save`.
- [`arch/`](arch/) - architecture-level changes rather than local edits: `!arch move`, `!arch sop`, `!arch extern`.

## Install for Codex

For Windows:

- Copy `coop/`, `mem/`, and `arch/` into `%USERPROFILE%\.codex\skills\`
