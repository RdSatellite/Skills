# !arch sop

> alias: `!sop`

## Description

Convert the architectural extension points explicitly provided by the user into standardized, reusable SOP Skills and store them in the agent/ext/ directory.

Treat the existing abstract architecture as the basis for determining extension boundaries, responsibilities, and integration procedures. Each generated skill should operationalize an extension point into a clear, repeatable procedure without unnecessarily expanding or redesigning the architecture.

## Hint

- Use the user's explicitly provided extension points as the source of truth. Guessing is forbidden.
