# !arch move

> alias: `!mv`

## Description

The user has decided to move the specified file (or code slices) to a certain location. You need to identify all the possible related changes that may arise and simultaneously modify them.

## Hint

- The user should have specified in the instruction the files to be moved and the destination location. Otherwise, you should stop executing this instruction and ask the user to clearly indicate them.
- The project is in an unstable state, so there is no need to attempt any verification or change to ensure the compilation is successful.
